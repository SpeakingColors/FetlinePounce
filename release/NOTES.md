FetlinePounce test build: a free, open source FET style limiting amplifier (VST3) by Studio 87.

This is a pre-release. The DSP core is tested; the installers and the plugin are NOT yet tried on real machines or in real DAWs.

Inside the zip: Windows installer, macOS package, Linux Flatpak extension and plain VST3 tarball, PDF manual, INSTALL.txt, LICENSE, SHA256SUMS.

The installers are not code signed. Windows may show an "unknown publisher" screen: More info, then Run anyway. macOS may block the package: System Settings, Privacy and Security, Open Anyway. Signing needs paid certificates, which this free project does not have.

Collects nothing; no network access.
