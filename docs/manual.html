FetlinePounce

A free, open source FET style limiting amplifier
Studio 87 · version 0.1.0 · VST3

Introduction

FetlinePounce is a fast limiting amplifier in the spirit of classic FET hardware. It squeezes loud peaks quickly, adds a little colour, and keeps punch. It is made for drums, vocals, bass and buses. It is free and open source.

It is inspired by the idea of that class of unit, not copied from any product; every number in it is our own design choice, written down in Under the hood.

Quick start

  • Load FetlinePounce on a track or bus.
  • Pick a preset with the arrows, or start with Ratio 4 and the Meter on GR.
  • Turn Input up until the needle shows 3 to 6 dB of gain reduction on the loud parts.
  • Lift Output until the level matches Bypass (press B to compare).
  • Use Mix below 100 percent for parallel compression.
  • Try the Listen HP key if the bass makes the limiter pump.

Signal flow

Input → (optional Listen HP, for the detector only) → level detector → gain computer (ratio, threshold, knee) → attack and release smoothing → gain stage with saturation (2x oversampled) → Output → Mix with the dry signal.

Under the hood

  • Ratios 4:1, 8:1, 12:1, 20:1 with fixed thresholds of -10, -8, -6 and -4 dBFS at the Input knob's 0 dB. These are our own design choices from the mockup, not measurements of any hardware.
  • All four ratio buttons: a special mode with ratio 16:1, threshold -5 dB, faster attack and slower release, plus more saturation. Our own design.
  • Static gain computer with a 4 dB soft knee. Level calibration: with the signal below the threshold, the output matches the input within 0.002 dB at every ratio (core test).
  • Detector: linked peak (the louder of left and right) with a 1 ms decay. Listen HP is a 2nd order Butterworth at 100 Hz on the detector only; the audio is not filtered.
  • Attack 20 to 800 microseconds and release 50 to 1100 ms. Release is program dependent: a short burst releases faster (116 ms in our test) than a long loud passage (245 ms, same setting).
  • Saturation: tanh with a drive that rises with gain reduction, inside a 2x oversampled path (61 tap linear phase half-band filters). Measured alias level on a 9.1 kHz sine at the hardest setting: about -77 dB (20:1) and -68 dB (all buttons, +30 dB input). Measured in the C++ core test, not yet in a host.
  • Latency: 30 samples at 44.1 and 48 kHz, 0 at 88.2 kHz and above (no oversampling there). The plugin reports it to the host exactly. Bypass is bit-exact: the input delayed by that latency, with a 10 ms crossfade when you switch.
  • Input, Output and Mix are smoothed with a 5 ms one-pole; a knob change is audible within one sample and reaches 63 % in about 5 ms.
  • Stability: silence, DC, full-scale square at +30 dB, NaN, infinity and denormals are handled (core tests with sanitizers). CPU in the core test: about 4 to 6.5 % of one core for stereo at 48 kHz with sanitizers on, so lighter in a normal build.
  • Not verified: how it sounds against a real 1176 style unit, any DAW other than pluginval, and the installers on real Windows, macOS and Linux machines.

Recommendations

  • Vocals: Ratio 4 or 8, slow Attack, medium Release, 3 to 6 dB of reduction.
  • Drums: Ratio 8 or 12, Attack around the middle, fast Release; All buttons for a room sound.
  • Bass: Listen HP on, Ratio 12, short Attack.
  • Buses: Ratio 4, light reduction (1 to 3 dB), Mix 100.
  • Always match the level with Bypass before judging the sound.

Install, remove, files

  • Windows: run Setup, it puts the VST3 in the common VST3 folder. Remove it from Settings, Apps. The installer is not signed, so Windows may warn; choose More info, then Run anyway.
  • macOS: open the .pkg. It is not notarized; if macOS blocks it, use System Settings, Privacy and Security, Open Anyway. Remove it with Uninstall FetlinePounce in Applications.
  • Linux Flatpak DAW: install the .flatpak from the linux folder with flatpak install --user, restart the DAW.
  • Linux native DAW: extract the tar.gz into ~/.vst3.
  • Your presets: Windows %APPDATA%\Studio 87\FetlinePounce\presets; macOS ~/Library/Application Support/Studio 87/FetlinePounce/presets; Linux ~/.local/share/Studio 87/FetlinePounce/presets.
