# FetlinePounce roadmap

## Done in v0.1.0 (test build)
- Native editor ported from the approved mockup; DSP core with tests; presets; installers for Windows, macOS, Linux; PDF manual with Interface tour.

## Not verified yet
- Sound compared with real FET hardware (all numbers are our own design choices).
- Installers on real Windows, macOS and Linux machines; the Flatpak extension in a real Flatpak DAW.
- Behaviour in real DAWs beyond pluginval; HiDPI and resizing in hosts.

## Next
- Test on real machines and fix what turns up.
- Sidechain input and external detector.
- Optional 4x oversampling (HQ) mode.
- Code signing, if a free route for open source becomes available.
